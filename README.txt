PLSC 508 Replication and Extension -- Yasin Shafi
====================================================================================

Study reproduced
  Right, Lucy, Jeremy Springman, and Erik Wibbels. 2025. "Pushing Back or Backing
  Down? Evidence on Donor Responses to Restrictive NGO Legislation." International
  Organization 79(4): 759-786. doi:10.1017/S0020818325100957
  Original replication files: Harvard Dataverse, doi:10.7910/DVN/FIINC8

Extension
  Treats the paper's donor-recipient aid data as yearly two-mode (bipartite)
  networks, 2005-2019: 19 OECD donors x ~107 recipients; a tie is a positive
  democracy-aid (or economic-aid) commitment in that year.


HOW TO RUN
------------------------------------------------------------------------------------
1. Download gsc_results.Rdata from the Dataverse record above and save it as
     data/gsc_results.Rdata
   (about 490 MB; too large for GitHub, so it is not in this repository).
   Without it, everything runs except the GSC figures/tables (paper Figures 4, 5, A2).
2. Open PLSC508_replication.Rproj in RStudio (or setwd() to this folder).
3. Run  source("run_all.R")  -- runs the four scripts in code/ in order (about 1 minute).
4. Compile paper/main.tex (pdflatex + bibtex). It reads figures from output/figures/
   and tables from output/tables/. On Overleaf, upload the whole repository and set
   paper/main.tex as the main document.

R packages
  Required: tidyverse, stargazer, gridExtra, lfe, network, igraph, patchwork
  Optional (paper's descriptive figures only): sf, rnaturalearth, rnaturalearthdata
    (Figure 1 map), panelView (Figure 3), interflex (Figures A1a-b). Sections that need
    a missing optional package are skipped with no effect on any estimate.
  To re-estimate the GSC models instead of loading them: gsynth, and set
    RUN_GSC <- TRUE in code/01_replication.R (several hours).
  ICEWS exploration (05, 06): data.table, countrycode, rmarkdown, knitr.
  Tested with R 4.3.3, lfe 3.1.1, stargazer 5.2.3.


FILES
------------------------------------------------------------------------------------
README.txt                  This file.
run_all.R                   Runs code/01-04 in order; regenerates every result in the PDF.
PLSC508_replication.Rproj   RStudio project; sets the working directory to the repo root.
.gitignore                  Keeps the 490 MB GSC file, derived .rds files, and LaTeX
                            build files out of git.

data/
  rsw_dataset.csv           Authors' dyad-year dataset (donor x recipient x year, 2005-2019):
                            aid commitments by sector and channel, NGO-law treatment
                            indicators, covariates. Unmodified copy from Dataverse.
                            Variable definitions: the authors' "!READ ME.txt" (Dataverse).
  icews_dyad_year.csv       ICEWS events aggregated to source x target x year (05). Raw
                            ICEWS files are not in the repo (Harvard Dataverse, ICEWS).
  gsc_results.Rdata         NOT IN REPO -- download from Dataverse (see HOW TO RUN).
                            Authors' saved generalized synthetic control estimates.

code/
  01_replication.R          Reproduction of the original study. The authors' script with
                            only these changes: relative paths; outputs to output/;
                            LaTeX table output; optional sections run only if their
                            packages are installed; GSC loaded from saved results unless
                            RUN_GSC = TRUE; label fix in Table A10 (Year-FE row filled
                            for all 6 columns). Writes output/rsw_prepared.rds (the data
                            with the paper's DOR/DOD orientation measures) for 02-04.
  02_build_network.R        Builds the yearly bipartite networks (network package) and the
                            dyad-year tie table; writes the network size/density table.
  03_network_plot.R         Network plots (Figures N1, N2).
  04_vertex_attributes.R    Vertex-attribute distributions for donors and recipients
                            (Figures V1, V2).
  05_icews_aggregate.R      Exploratory (not in the PDF). Aggregates raw ICEWS event files
                            (local folder set in ICEWS_DIR) to directed country-dyad-year
                            counts by CAMEO quad class -> data/icews_dyad_year.csv.
  06_icews_explore.Rmd      Exploratory (not in the PDF). Knit after 02 and 05. Two-mode
                            donor->recipient ICEWS vs CRS ties, weighted recipient-recipient
                            cooperation layer, patron shares around NGO laws, tie
                            persistence, cross-layer triangles -> output/06_icews_explore.html

output/                     Everything here is generated by the scripts.
  tables/tab_1_*, tab_2_*, tab_A*, tab_NR_*   Reproduced tables (01_replication.R)
  tables/tab_network_desc.tex                 Network size and density by year (02)
  figures/fig_2_*, fig_A3_*, fig_A4_*         Reproduced paper figures (01)
  figures/fig_4*, fig_5*, fig_A2*, fig_NR_*   Reproduced GSC figures (01; need gsc_results.Rdata)
  figures/fig_N1_network_2014_2019.*          Full democracy-aid network, 2014 vs 2019 (03)
  figures/fig_N2_south_asia_2014_2019.*       South Asia sub-network, 2014 vs 2019 (03)
  figures/fig_V1_donor_attributes.*           Donor attribute histograms (04)
  figures/fig_V2_recipient_attributes.*       Recipient attribute histograms (04)
  rsw_prepared.rds, network_grid.rds,
  nets_dem.rds, nets_econ.rds                 Intermediate R objects (01, 02); not in git.
  replication_log.txt                         Console log of a full run of 01.

paper/
  main.tex                  The submitted PDF's source.
  references.bib            Bibliography.
  main.pdf                  Compiled PDF.

REPRODUCTION CHECK
------------------------------------------------------------------------------------
All 14 two-way fixed-effects tables written by 01_replication.R were compared with the
authors' shipped .tex files (ignoring timestamps and line endings): all are identical
except Table A10, which differs only in the corrected Year-FE label row. Tables 1 and 2
also match the published article.
